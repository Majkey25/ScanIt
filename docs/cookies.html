This website

These GitHub Pages use static HTML and local stylesheets and images. The site does not add analytics, advertising cookies, tracking pixels, embedded videos, third-party widgets, web fonts, forms or scripts that read or write browser storage.

No optional tracking is requested here, so this site does not present a cookie-consent banner. A banner would not replace the need to prevent optional tracking before consent. The Czech data protection authority's cookie guidance explains the distinction.

Hosting and external links

GitHub Pages receives ordinary network requests and may record IP addresses for hosting and security. Browser caching of public pages is separate from advertising tracking. See GitHub's privacy statement.

Google Play, GitHub and Buy Me a Coffee links open external services only when you select them. Their own privacy and cookie rules apply after navigation. They are not embedded on these pages.

Advertising in the Android app

The separately maintained Google Play edition includes Google advertising and consent SDKs. The stable GitHub edition does not. This is separate from the website. The app checks Google's consent status before requesting ads and shows an ad-privacy-options control when Google requires it.

Use that control to review your choices. Declining personalized advertising is not a Premium purchase. See the privacy policy for identifiers, diagnostics and other SDK data. Premium removes ads after Google Play confirms the entitlement.

# Contributing to SeliaScan

Bug reports and focused feature suggestions are welcome through
[GitHub Issues](https://github.com/Majkey25/ScanIt/issues).

Before reporting a bug:

- use the latest public release;
- include the SeliaScan version, Android version, and reproducible steps;
- never attach private documents, credentials, file URIs, or device identifiers.

Code pull requests are not currently accepted. SeliaScan is source-visible under
proprietary terms, and there is no contributor-license process in place. Please
open an issue before doing implementation work.

Report security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/Majkey25/ScanIt/security/advisories/new),
not a public issue.
